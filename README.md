# Sign-up Form

A responsive sign-up form for an imaginary online service, built with **HTML and CSS**.

This project was created as part of my learning journey to practice building forms, working with HTML form elements, and applying CSS layouts and styling.

## Features

* First and last name fields
* Email input with HTML validation
* Phone number input
* Password and password confirmation fields
* Required field validation
* Custom form styling
* Image-based visual design
* Responsive layout using CSS

## Technologies

* **HTML5** — Form structure and semantic elements
* **CSS3** — Layout, styling and form validation states

## What I Learned

* Creating forms using HTML
* Using different HTML input types
* Connecting labels to form inputs
* Using `required` for basic form validation
* Using HTML's built-in email validation
* Styling form inputs and buttons
* Using CSS Flexbox for page layout
* Positioning elements over images
* Using CSS pseudo-classes such as `:valid` and `:invalid`
* Creating a responsive two-section layout

## Form Fields

The form contains:

| Field            | Input Type | Required |
| ---------------- | ---------- | -------- |
| First Name       | Text       | No       |
| Last Name        | Text       | No       |
| Email            | Email      | Yes      |
| Phone Number     | Number     | No       |
| Password         | Password   | Yes      |
| Confirm Password | Password   | Yes      |

The email, password and confirmation fields use HTML's built-in `required` validation. Inputs also change their border colour based on their validation state.

## What This Project Demonstrates

This project focuses on **frontend fundamentals**, particularly creating structured HTML forms and using CSS to build a visually appealing layout.

It was an early project in my development journey and helped me build a stronger foundation before moving on to more complex JavaScript and full-stack applications.
